# Pensar Skills

A collection of [Cursor Agent Skills](https://docs.cursor.sh/context/skills) used by Pensar for common development workflows.

## Skills

| Skill | Description |
|-------|-------------|
| [dockerize-app](dockerize-app/) | Dockerize an application with docker-compose, database provisioning, data seeding, and full dev environment setup |

## Usage

These skills are designed to be referenced from `.cursor/skills/` in any project. Copy or symlink the desired skill directory into your project's `.cursor/skills/` folder, or add them to your personal `~/.cursor/skills/` directory.
